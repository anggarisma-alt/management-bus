# SiBus Web (frontend)

Frontend statis untuk GitHub Pages. Backend: Google Apps Script (`sibus-api/Kode.gs`, repo terpisah/folder terpisah).

1. Isi `GAS_URL` di `js/config.js` dengan URL Web App (`.../exec`).
2. Push ke GitHub, aktifkan Pages (Settings > Pages > Branch `main` / root).
3. Buka `https://USERNAME.github.io/NAMA-REPO/`.
